CATLOCK / SUPPORT

Help your cat get started

For CatLock 1.0 · Build 3

Getting started: no Accessibility permission needed

  1. Open CatLock and follow onboarding to name your cat, choose its appearance, and set an unlock phrase. The default phrase is cat. No Accessibility permission is required.
  2. Click the desktop cat or choose Turn On Protection from the paw menu in the menu bar.
  3. Your desktop stays visible, while ordinary typing and mouse clicks do not reach the apps underneath. Unlock before using other apps.
  4. Type your unlock phrase or hold the guarding cat with your mouse for 3 seconds to unlock. In the default mode, you can also press Esc.

Switching to another app or Space ends the default lock. Some system keys, such as brightness and volume controls, may remain available.

Optional: keep using your mouse while locked

To click, scroll, or use other apps while the keyboard is locked, open Settings → Protection & Unlock → Additional options and enable “Allow mouse use while locked”. This option is off by default and requires Accessibility permission.

  1. After enabling the option, follow the prompt to allow CatLock in System Settings → Privacy & Security → Accessibility. On macOS 11/12, use System Preferences → Security & Privacy → Privacy → Accessibility.
  2. Return to CatLock and confirm that the option is enabled, then click the cat to lock. Keyboard input is blocked while your mouse and trackpad can interact with other apps.
  3. Type your unlock phrase or hold the cat for 3 seconds to unlock. Esc unlock is available only in the default mode.

Declining permission leaves the default mode available. Turn “Allow mouse use while locked” off to return to default locking, even if system permission remains granted.

Forgot your phrase or cannot unlock?

Hold the guarding cat for 3 seconds. In the default mode, you can also press Esc. After unlocking, use Settings → Protection & Unlock to change your phrase or restore the default phrase, cat.

Phrases contain 3–8 English letters or numbers; letters are treated as lowercase. Phrases are recognized by US keyboard positions. On AZERTY, QWERTZ, Dvorak, or other layouts, key labels may not match the recognized characters. You can hold the cat for 3 seconds to unlock instead. Do not use your Mac login password as an unlock phrase.

Optional mouse mode: permission is enabled, but CatLock is still waiting

Quit and reopen CatLock first. Switching from a local preview to TestFlight or a formally signed version may leave an old permission entry. If access is still not recognized, remove the old CatLock entry from Accessibility, add the current CatLock from Applications with the “+” button, enable it, and reopen the app. Only change the CatLock entry. If you do not need optional mouse control, turn the option off and continue using the default lock.

Why did onboarding not appear again?

Completion is stored locally. If this macOS user account has used CatLock before, reinstalling may open the desktop cat directly. Use the paw menu → How CatLock Works for instructions. Change the cat name, appearance, and phrase in Settings. This version has no full onboarding replay button.

Where is my desktop cat?

Check the paw menu in the menu bar and the option to show the desktop cat in Settings. CatLock can run without a Dock icon. Closing Settings does not quit the app.

Scope and compatibility

CatLock prevents accidental input; it is not a security screen lock. The default mode blocks mouse clicks from reaching underlying apps; the optional mouse mode lets you interact with other apps. Neither mode guarantees interception of every system-level or hardware key. Use the macOS lock screen to secure your Mac when leaving it unattended.

The app includes English and Simplified Chinese interfaces. The current build targets macOS 11.0 or later and includes Apple Silicon and Intel support; consult the actual store listing and verified compatibility information.
