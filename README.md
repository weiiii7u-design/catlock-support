# Help your cat get started

For CatLock 1.0.0 · Build 1

## Getting started

- Open CatLock and follow onboarding to name your cat, choose its appearance, and set an unlock phrase.
- Allow CatLock in System Settings → Privacy & Security → Accessibility. On macOS 11/12, use System Preferences → Security & Privacy → Privacy → Accessibility.
- Click the desktop cat or choose Turn On Protection from the paw menu in the menu bar.
- Type your unlock phrase or hold the guarding cat with your mouse for 3 seconds. Your mouse and trackpad remain available.

## Forgot your phrase or cannot unlock?

Hold the guarding cat for 3 seconds, or turn protection off from the menu bar. Then use Settings → Protection & Unlock to change your phrase or restore the default phrase, `cat`.

Phrases contain 3–8 English letters or numbers; letters are treated as lowercase. Version 1.0.0 Build 1 recognizes US keyboard positions. On AZERTY, QWERTZ, Dvorak, or other layouts, key labels may not match the recognized characters. Use mouse unlock and contact support if affected. Do not use your Mac login password as an unlock phrase.

## Permission is enabled, but CatLock is still waiting

Switching from a local test build to TestFlight or a formally signed version may leave an old permission entry. Quit CatLock, remove its old entry from Accessibility, add the current CatLock from Applications with the “+” button, enable it, and reopen the app. Only change the CatLock entry.

## Why did onboarding not appear again?

Completion is stored locally. If this macOS user account has used CatLock before, reinstalling may open the desktop cat directly. Use the paw menu → How CatLock Works for instructions. Change the cat name, appearance, and phrase in Settings. This version has no full onboarding replay button.

## Where is my desktop cat?

Check the paw menu in the menu bar and the option to show the desktop cat in Settings. CatLock can run without a Dock icon. Closing Settings does not quit the app.

## Scope and compatibility

CatLock prevents accidental typing; it is not a security screen lock. It does not block mouse input and cannot guarantee interception of every system-level or hardware key. Use the macOS lock screen to secure your Mac when leaving it unattended.

The app includes English and Simplified Chinese interfaces. The current build targets macOS 11.0 or later and includes Apple Silicon and Intel support; consult the actual store listing and verified compatibility information.

# 让猫咪开始守护

适用于 CatLock 1.0.0 · Build 1

## 开始使用

- 打开 CatLock，跟随引导为猫咪取名、选择外观并设置解锁口令。
- 在“系统设置 → 隐私与安全性 → 辅助功能”中允许 CatLock。macOS 11/12 的入口称为“系统偏好设置 → 安全性与隐私 → 隐私 → 辅助功能”。
- 点击桌面猫咪，或从顶部爪印菜单选择开启保护。
- 输入解锁口令，或用鼠标按住守护中的猫咪 3 秒解除保护。鼠标和触控板保持可用。

## 忘记口令或无法解锁

先用鼠标按住守护中的猫咪 3 秒；也可以使用菜单栏中的解除保护操作。解除后，在设置的“保护与解锁”页面修改口令或恢复默认口令 `cat`。

口令为 3–8 位英文字母或数字，字母按小写处理。1.0.0 Build 1 按美式键位识别口令，AZERTY、QWERTZ、Dvorak 等布局可能与按键标签不一致；遇到这种情况使用鼠标解锁，并联系支持。不要把 Mac 登录密码用作解锁口令。

## 已打开权限，但仍显示等待授权

从本地测试版本切换到 TestFlight 或正式签名版本时，系统可能保留旧版本授权。先退出 CatLock，在辅助功能列表移除旧 CatLock 项目，再用「＋」添加“应用程序”中的当前 CatLock，打开开关并重新启动。只操作 CatLock 项目。

## 为什么没有再次出现新手引导

完成记录会保存在本机。同一 macOS 用户账户之前使用过 CatLock，重新安装后可能直接显示桌面猫咪。可通过顶部爪印菜单的“使用说明”查看操作方法，在设置中更改名字、外观和口令。当前版本没有完整引导的重播按钮。

## 找不到桌面猫咪

先查看顶部菜单栏的爪印菜单，并在设置中确认桌面猫咪显示选项已开启。CatLock 可以不显示 Dock 图标，关闭设置窗口也不等于退出应用。

## 适用范围

CatLock 是防误触工具，不是安全锁屏。它不阻止鼠标操作，也不保证拦截所有系统级或硬件按键。离开电脑需要保护隐私时，请使用 macOS 自带的锁屏功能。

应用支持简体中文和英文；当前构建配置要求 macOS 11.0 或更高版本，支持 Apple Silicon 与 Intel Mac。系统版本兼容性以实际商店信息及验证结果为准。
