CATLOCK / SUPPORT

让猫咪开始守护

适用于 CatLock 1.0.0 · Build 1

开始使用

  1. 打开 CatLock，跟随引导为猫咪取名、选择外观并设置解锁口令。
  2. 在“系统设置 → 隐私与安全性 → 辅助功能”中允许 CatLock。macOS 11/12 的入口称为“系统偏好设置 → 安全性与隐私 → 隐私 → 辅助功能”。
  3. 点击桌面猫咪，或从顶部爪印菜单选择开启保护。
  4. 输入解锁口令，或用鼠标按住守护中的猫咪 3 秒解除保护。鼠标和触控板保持可用。

忘记口令或无法解锁

先用鼠标按住守护中的猫咪 3 秒；也可以使用菜单栏中的解除保护操作。解除后，在设置的“保护与解锁”页面修改口令或恢复默认口令 cat。

口令为 3–8 位英文字母或数字，字母按小写处理。1.0.0 Build 1 按美式键位识别口令，AZERTY、QWERTZ、Dvorak 等布局可能与按键标签不一致；遇到这种情况使用鼠标解锁，并联系支持。不要把 Mac 登录密码用作解锁口令。

已打开权限，但仍显示等待授权

从本地测试版本切换到 TestFlight 或正式签名版本时，系统可能保留旧版本授权。先退出 CatLock，在辅助功能列表移除旧 CatLock 项目，再用「＋」添加“应用程序”中的当前 CatLock，打开开关并重新启动。只操作 CatLock 项目。

为什么没有再次出现新手引导

完成记录会保存在本机。同一 macOS 用户账户之前使用过 CatLock，重新安装后可能直接显示桌面猫咪。可通过顶部爪印菜单的“使用说明”查看操作方法，在设置中更改名字、外观和口令。当前版本没有完整引导的重播按钮。

找不到桌面猫咪

先查看顶部菜单栏的爪印菜单，并在设置中确认桌面猫咪显示选项已开启。CatLock 可以不显示 Dock 图标，关闭设置窗口也不等于退出应用。

适用范围

CatLock 是防误触工具，不是安全锁屏。它不阻止鼠标操作，也不保证拦截所有系统级或硬件按键。离开电脑需要保护隐私时，请使用 macOS 自带的锁屏功能。

应用支持简体中文和英文；当前构建配置要求 macOS 11.0 或更高版本，支持 Apple Silicon 与 Intel Mac。系统版本兼容性以实际商店信息及验证结果为准。
