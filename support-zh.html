让猫咪开始守护

适用于 CatLock 1.0 · Build 3

开始使用：默认免权限锁定

  1. 打开 CatLock，跟随引导为猫咪取名、选择外观并设置解锁口令。默认口令是 cat，无需开启辅助功能权限。
  2. 点击桌面猫咪，或从顶部爪印菜单选择开启保护。
  3. 桌面仍然可见，普通按键和鼠标点击不会传到下方的应用。要操作其他软件，请先解锁。
  4. 输入解锁口令，或用鼠标按住守护中的猫咪 3 秒解除保护。默认模式也可以按 Esc 解锁。

默认模式下，切换到其他应用或桌面空间会解除保护。部分系统按键，如亮度和音量键，可能仍可使用。

可选：锁定时继续使用鼠标

如果想在键盘锁定时用鼠标点击、滚动或操作其他软件，可进入“设置 → 保护与解锁 → 附加选项”，开启“锁定时允许使用鼠标”。此选项默认关闭，需要辅助功能权限。

  1. 主动开启该选项后，按提示进入“系统设置 → 隐私与安全性 → 辅助功能”，允许 CatLock。macOS 11/12 的入口是“系统偏好设置 → 安全性与隐私 → 隐私 → 辅助功能”。
  2. 返回 CatLock，确认选项已开启，再点击猫咪锁定。此时键盘输入被拦截，鼠标和触控板可操作其他软件。
  3. 输入解锁口令，或按住猫咪 3 秒解锁。Esc 解锁仅适用于默认模式。

不授权也能使用默认锁定。关闭“锁定时允许使用鼠标”即可切回默认模式，即使系统中仍保留辅助功能授权。

忘记口令或无法解锁

先用鼠标按住守护中的猫咪 3 秒；默认模式也可以按 Esc。解除后，在设置的“保护与解锁”页面修改口令或恢复默认口令 cat。

口令为 3–8 位英文字母或数字，字母按小写处理。口令按美式键位识别，AZERTY、QWERTZ、Dvorak 等布局可能与按键标签不一致；遇到这种情况可以按住猫咪 3 秒解锁。不要把 Mac 登录密码用作解锁口令。

可选鼠标模式：已打开权限，但仍显示等待授权

先退出并重新打开 CatLock。如果从本地预览版本切换到 TestFlight 或正式签名版本，系统可能保留旧的授权记录。仍无法识别时，在辅助功能列表移除旧 CatLock 项目，再用「＋」添加“应用程序”中的当前 CatLock，打开开关并重新启动。只操作 CatLock 项目。无需使用可选鼠标模式时，可以关闭该选项，继续使用默认锁定。

为什么没有再次出现新手引导

完成记录会保存在本机。同一 macOS 用户账户之前使用过 CatLock，重新安装后可能直接显示桌面猫咪。可通过顶部爪印菜单的“使用说明”查看操作方法，在设置中更改名字、外观和口令。当前版本没有完整引导的重播按钮。

找不到桌面猫咪

先查看顶部菜单栏的爪印菜单，并在设置中确认桌面猫咪显示选项已开启。CatLock 可以不显示 Dock 图标，关闭设置窗口也不等于退出应用。

适用范围

CatLock 是防误触工具，不是安全锁屏。默认模式会阻止鼠标点击下方应用；可选鼠标模式允许操作其他软件。两种模式都不保证拦截所有系统级或硬件按键。离开电脑需要保护隐私时，请使用 macOS 自带的锁屏功能。

应用支持简体中文和英文；当前构建配置要求 macOS 11.0 或更高版本，支持 Apple Silicon 与 Intel Mac。系统版本兼容性以实际商店信息及验证结果为准。
